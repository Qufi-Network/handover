Connect Handover to Veyns

  1. Open the Veyns developer console and sign in.
  2. Register an application with exactly these values:
    Application name
    Handover
    Website origin
    Redirect URI
    ID token signature
    ES256
  3. Paste the client ID it gives you.
  4. Add it as VEYNS_CLIENT_ID in your hosting environment variables (Vercel → Settings → Environment Variables), then redeploy.
